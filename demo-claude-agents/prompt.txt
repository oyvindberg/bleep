Scripted demo - follow EXACTLY, no improvisation, edit no files.
The cwd is a compiled bleep repo (MAIN); its absolute path is `pwd`.

1. Run: git worktree add -b seeded ../wt-seeded
        git worktree add -b cold   ../wt-cold

2. Spawn two subagents IN PARALLEL (one message, two Agent calls):

   - seeded: "Using the bleep MCP tools: call copy-state with
     directory=<MAIN>/../wt-seeded and from=<MAIN>, then call compile
     for the same directory. Report both results verbatim."

   - cold: "Using the bleep MCP tools: call compile with
     directory=<MAIN>/../wt-cold. Do NOT call copy-state - this
     worktree deliberately starts cold. Report the result verbatim."

3. Each reports historyId=1 in its own worktree. Ask bleep to compare
   the two runs: call the history diff-timing tool with
   directory=<MAIN>/../wt-seeded, base=1, target=1,
   baseDirectory=<MAIN>/../wt-cold.

4. Print exactly this, with real numbers from the tool results:
   agent[seeded]  copy-state: <bytes> bytes in <ms>  ->  first compile: success
   agent[cold]    first compile: success (compiled everything from scratch)
   bleep history diff-timing (cold -> seeded): total <totalBaseMs>ms -> <totalTargetMs>ms
   verdict: <one sentence with the ratio>
Then stop.
