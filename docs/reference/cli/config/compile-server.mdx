# `bleep config compile-server`

<p>You can speed up normal usage by keeping the compile server running between invocations. This is where you control it</p>

## Synopsis

```bash
bleep config compile-server <subcommand>
```

## `bleep config compile-server auto-shutdown-disable`

<p>(deprecated: use `bleep server config mode shared`) leave compile servers running between bleep invocations</p>

## `bleep config compile-server auto-shutdown-enable`

<p>(deprecated: use `bleep server config mode per-invocation`) shut down the compile server between bleep invocations</p>

## `bleep config compile-server stop-all`

<p>(deprecated: use `bleep server stop-all`) stop every shared compile server currently running</p>

### Synopsis

```bash
bleep config compile-server stop-all [flags]
```

### Flags

| Flag | Description |
|------|-------------|
| `--force` | skip the graceful path: kill immediately and delete the socket directory |

## `bleep config compile-server max-memory`

<p>(deprecated: use `bleep server config max-memory`) set max heap for compile server JVM</p>

### Synopsis

```bash
bleep config compile-server max-memory <size>
```

### Arguments

| Argument | Type |
|----------|------|
| `size` | one |

## `bleep config compile-server max-memory-clear`

<p>remove compile server max heap setting (back to default: 1/4 of physical RAM, clamped to 4g..16g)</p>

## `bleep config compile-server parallelism`

<p>(deprecated: use `bleep server config parallelism`) set how many operations may run at once — compiles, test forks, sourcegen (default: one per core)</p>

### Synopsis

```bash
bleep config compile-server parallelism <n>
```

### Arguments

| Argument | Type |
|----------|------|
| `n` | one |

## `bleep config compile-server parallelism-clear`

<p>(deprecated: use `bleep server config parallelism-clear`) remove the parallelism setting (back to default: one per core)</p>

## `bleep config compile-server max-cached-workspaces`

<p>set how many workspaces' builds stay warm in the server (default: one per GB of server heap, at least 2). Evicted ones reload on next use</p>

### Synopsis

```bash
bleep config compile-server max-cached-workspaces <n>
```

### Arguments

| Argument | Type |
|----------|------|
| `n` | one |

## `bleep config compile-server max-cached-workspaces-clear`

<p>(deprecated: use `bleep server config max-cached-workspaces-clear`) remove the setting (back to default: one per GB of server heap, at least 2)</p>

## `bleep config compile-server read-timeout`

<p>set minutes the server waits for a client's next message before dropping the connection, 0 to wait forever (default: 30)</p>

### Synopsis

```bash
bleep config compile-server read-timeout <minutes>
```

### Arguments

| Argument | Type |
|----------|------|
| `minutes` | one |

## `bleep config compile-server read-timeout-clear`

<p>remove read timeout setting (use default: 30 minutes)</p>

## `bleep config compile-server idle-timeout`

<p>set minutes the server stays alive with no connected client before shutting itself down, 0 to stay alive forever (default: 60)</p>

### Synopsis

```bash
bleep config compile-server idle-timeout <minutes>
```

### Arguments

| Argument | Type |
|----------|------|
| `minutes` | one |

## `bleep config compile-server idle-timeout-clear`

<p>remove idle timeout setting (use default: 60 minutes)</p>
