# `bleep history`

<p>list this workspace's recorded compile/test runs (written by the compile server, kept per worktree)</p>

## Synopsis

```bash
bleep history <subcommand> [args] [flags]
```

## Subcommands

- [`bleep history show`](./show): print the full transcript of a recorded compile/test run as JSON (latest when no id is given)
- [`bleep history diff`](./diff): diff two recorded runs: what logically changed (or, with --timing, what got slower/faster)
