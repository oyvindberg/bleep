# `bleep server`

<p>inspect and control the compile servers (bsp daemons) running on this machine</p>

## Synopsis

```bash
bleep server <subcommand> [args] [flags]
```

## Subcommands

- [`bleep server ls`](./ls): list every compile server on this machine, running or not
- [`bleep server status`](./status): detailed status for one compile server
- [`bleep server kill`](./kill): stop compile servers — gracefully over the protocol, escalating only if that does not work
- [`bleep server stop-all`](./stop-all): stop every compile server — exactly `kill --all`, spelled the way people reach for it
- [`bleep server restart`](./restart): stop a compile server so the next build starts a fresh one with the current config
- [`bleep server log`](./log): print a compile server's log; -f to follow
- [`bleep server metrics`](./metrics): open the compile server metrics dashboard in a browser
