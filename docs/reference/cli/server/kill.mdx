# `bleep server kill`

<p>stop compile servers — gracefully over the protocol, escalating only if that does not work</p>

## Synopsis

```bash
bleep server kill <id...> [flags]
```

## Arguments

| Argument | Type |
|----------|------|
| `id` | one or more |

## Flags

| Flag | Description |
|------|-------------|
| `--all` | stop every compile server on this machine |
| `--force` | skip the graceful path: kill immediately and delete the socket directory |
