bleep server config

show and change the settings compile servers start with

Synopsis​

bleep server config <subcommand>

bleep server config show​

every setting, what it is set to, and what the running server actually booted with

Synopsis​

bleep server config show [flags]

Flags​

FlagDescription
--output, -o <string>output format: text, json, or raw

bleep server config mode​

shared (keep the server warm between invocations) or per-invocation (shut it down each time, slower but frees memory)

Synopsis​

bleep server config mode <shared|per-invocation>

Arguments​

ArgumentType
`sharedper-invocation`

bleep server config parallelism​

how many operations may run at once — compiles, test forks, sourcegen (default: one per core)

Synopsis​

bleep server config parallelism <n>

Arguments​

ArgumentType
none

bleep server config parallelism-clear​

remove the parallelism setting (back to default: one per core)

bleep server config parallelism-ratio​

the same as a fraction of cores, e.g. 0.5 for half. Used when parallelism is unset

Synopsis​

bleep server config parallelism-ratio <ratio>

Arguments​

ArgumentType
ratioone

bleep server config parallelism-ratio-clear​

remove the parallelism ratio

bleep server config max-memory​

max heap for the compile server JVM (e.g. 4g, 2048m)

Synopsis​

bleep server config max-memory <size>

Arguments​

ArgumentType
sizeone

bleep server config max-memory-clear​

remove the compile server max heap setting (back to default: 1/4 of physical RAM, clamped to 4g..16g)

bleep server config max-cached-workspaces​

how many workspaces' builds stay warm in the server (default: one per GB of server heap, at least 2). Evicted ones reload on next use

Synopsis​

bleep server config max-cached-workspaces <n>

Arguments​

ArgumentType
none

bleep server config max-cached-workspaces-clear​

remove the setting (back to default: one per GB of server heap, at least 2)

bleep server config read-timeout​

minutes the server waits for a client's next message before dropping the connection; 0 waits forever

Synopsis​

bleep server config read-timeout <minutes>

Arguments​

ArgumentType
minutesone

bleep server config read-timeout-clear​

remove the read timeout setting (back to default: 30 minutes)

bleep server config idle-timeout​

minutes a server with no connected client stays alive before shutting itself down; 0 disables

Synopsis​

bleep server config idle-timeout <minutes>

Arguments​

ArgumentType
minutesone

bleep server config idle-timeout-clear​

remove the idle timeout setting (back to default: 60 minutes)

bleep server config heap-pressure-threshold​

heap fraction (0.0-1.0) above which new compilations wait for memory (default: 0.80)

Synopsis​

bleep server config heap-pressure-threshold <fraction>

Arguments​

ArgumentType
fractionone

bleep server config heap-pressure-threshold-clear​

remove the setting (back to default: 0.80)

bleep server config test-runner-heap​

default heap for forked test runner JVMs (e.g. 512m, 2g). A project's own platform.jvmOptions -Xmx overrides it

Synopsis​

bleep server config test-runner-heap <size>

Arguments​

ArgumentType
sizeone

bleep server config test-runner-heap-clear​

remove the setting (back to bleep's default: 2048m per test fork)

bleep server config test-runner-max-memory​

(deprecated: use bleep server config test-runner-heap)

Synopsis​

bleep server config test-runner-max-memory <size>

Arguments​

ArgumentType
sizeone

bleep server config test-runner-max-memory-clear​

(deprecated: use bleep server config test-runner-heap-clear)

bleep server config test-idle-timeout​

minutes a test suite may go without emitting an event before it is considered stuck (default: 2)

Synopsis​

bleep server config test-idle-timeout <minutes>

Arguments​

ArgumentType
minutesone

bleep server config test-idle-timeout-clear​

remove the test idle timeout setting (back to default: 2 minutes)

bleep server config sourcegen-max-memory​

max heap for forked sourcegen JVMs (e.g. 500m, 2g)

Synopsis​

bleep server config sourcegen-max-memory <size>

Arguments​

ArgumentType
sizeone

bleep server config sourcegen-max-memory-clear​

remove the sourcegen max heap setting (back to the JVM default)

bleep server config ksp-runner-max-memory​

max heap for forked KSP runner JVMs (e.g. 512m, 1500m)

Synopsis​

bleep server config ksp-runner-max-memory <size>

Arguments​

ArgumentType
sizeone

bleep server config ksp-runner-max-memory-clear​

remove the KSP runner max heap setting (back to the JVM default)
