# `bleep server restart`

<p>stop a compile server so the next build starts a fresh one with the current config</p>

## Synopsis

```bash
bleep server restart <id...> [flags]
```

## Arguments

| Argument | Type |
|----------|------|
| `id` | one or more |

## Flags

| Flag | Description |
|------|-------------|
| `--all` | restart every running compile server |
