# `bleep server config`

<p>show and change the settings compile servers start with</p>

## Synopsis

```bash
bleep server config <subcommand>
```

## `bleep server config show`

<p>every setting, what it is set to, and what the running server actually booted with</p>

### Synopsis

```bash
bleep server config show [flags]
```

### Flags

| Flag | Description |
|------|-------------|
| `--output, -o <string>` | output format: text, json, or raw |

## `bleep server config mode`

<p>shared (keep the server warm between invocations) or per-invocation (shut it down each time, slower but frees memory)</p>

### Synopsis

```bash
bleep server config mode <shared|per-invocation>
```

### Arguments

| Argument | Type |
|----------|------|
| `shared|per-invocation` | one |

## `bleep server config parallelism`

<p>how many operations may run at once — compiles, test forks, sourcegen (default: one per core)</p>

### Synopsis

```bash
bleep server config parallelism <n>
```

### Arguments

| Argument | Type |
|----------|------|
| `n` | one |

## `bleep server config parallelism-clear`

<p>remove the parallelism setting (back to default: one per core)</p>

## `bleep server config parallelism-ratio`

<p>the same as a fraction of cores, e.g. 0.5 for half. Used when parallelism is unset</p>
