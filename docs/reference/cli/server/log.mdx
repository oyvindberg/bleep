# `bleep server log`

<p>print a compile server's log; -f to follow</p>

## Synopsis

```bash
bleep server log <id> [flags]
```

## Arguments

| Argument | Type |
|----------|------|
| `id` | one |

## Flags

| Flag | Description |
|------|-------------|
| `--lines, -n <integer>` | how many lines to print (default 100) |
| `--follow, -f` | keep printing as the log grows |
| `--generation <integer>` | 0 = current log, 1 or 2 = rotated (a crashed daemon's log is usually here) |
